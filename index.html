Cara Menjadikan Web (Dapat Link)

1 Netlify Drop (Paling Mudah - 10 Detik) Tanpa Coding
  1. Unduh file dengan mengklik tombol hijau "Download index.html" di atas.
  2. Buka link: app.netlify.com/drop
  3. Seret (Drag & Drop) file index.html ke kotak yang tersedia di layar.
  4. Selesai! Anda langsung dapat link web untuk dibagikan ke teman.

Muncul Pesan "Page Not Found / 404"?

Pastikan nama file di komputer Anda persis index.html (huruf kecil semua, tanpa .txt atau spasi) sebelum di-drop ke Netlify.

2 GitHub Pages (Permanen & Rapi) Gratis Selamanya
  1. Buat akun gratis di github.com.
  2. Buat Repository Baru, beri nama thailand-trip.
  3. Upload file index.html ini.
  4. Buka Settings ➔ Pages, ubah Branch ke main lalu klik Save. Link web Anda akan aktif!

Tips Penting Berbagi Data:

Setelah teman Anda membuka link web, kirimkan file cadangan .json (dapat diunduh lewat tombol "Backup") ke WhatsApp group. Teman Anda tinggal menekan tombol "Upload" di web untuk menampilkan seluruh data itinerary yang persis sama!
